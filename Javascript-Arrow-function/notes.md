Arrow function : 
ex. 
let func = (arg1, arg2, ..., argN) => expression;

it is a shorter version of - 
ex. 
let func = function(arg1, agr2, ..., argN){
    return expression;
};

Multiple Arrow function :
when needed more complex function with multiple expressions and statements, we enclosed them in curly braces. 
curly braces required a return to return a value (just like a regular function).


summary : 
1. Without curly braces: (...args) => expression
2. With curly braces: (...args) => { body }
