Sync in JS:
1. Synchronous means the code runs in a particular sequence of instructions given inthe program.
2. Each instruction waits for the previous instruction to complete its execution.

Async in JS
Due to synchronous programming, sometimes IMP instructions get blocked to some previous instructions, which causes a delay in the UI.
Asynchronous code execution allows to execute next instructions immediately and dosen't block the flow.

Callbacks : 
A callback is a function passed as an argument to another function.

Callback Hell:
nested callbacks stacked below one another forming a pyramid structure.
(Pyramid of doom)
This styling of programming becomes difficult to understand and manage.

Async - Await : 
- async function always returns a promise
- it returns a promise.

Await pauses the execution of its surrounding async function until the promise is settled.
